# Dronariane – C'Space 2026

Dronariane is a rocket project developed for the C'Space 2026 campaign. This repository contains the onboard electronics software, the ground receiver, the flight sequencer, component test programs, and a Processing simulation used to analyse the Payload's orientation.

## Main systems

### Main onboard computer

The `Onboard computer` directory contains the software for the rocket's main onboard computer, based on a Teensy 4.1.

The system is connected to:
- A microSD card reader for data logging
- An LoRa transmitter (RMF95W)
- A GPS module (NEO6MV2)
- A BMI088 IMU
- An MS5611 barometer
- A RunCam Split 4 camera

All components passed their individual tests. However, when the complete system was assembled, intermittent recording issues appeared. Depending on the flight period, either sensor data or camera footage could be affected. These issues also impacted other functions, including LoRa transmission.

The flight data was not recovered and no LoRa signal was received during the C'Space launch. The complete flight video was the only onboard recording successfully recovered.

The suspected cause is a power-supply issue. The Teensy 4.1 and the camera share the same PCB power trace (daisy-chain wiring) powered by a 9V battery. Current peaks generated by the camera and the internal buck converter can cause voltage drops along this shared line, potentially disrupting both the camera and the Teensy. We initially chose 9V batteries for their ease of charging (via USB) and simple integration, but in the future, a LiPo battery should be preferred over a 9V battery to prevent these sudden voltage drops. 
Additionally, instead of daisy-chaining, a star wiring topology from the power source should have been used. Furthermore, voltage drops affecting operation could have been mitigated by isolating the branches with resettable (PTC) fuses and adding a Schottky diode with an electrolytic hold-up capacitor on the Teensy's supply line to prevent brownouts. 

### Payload

The `Payload` directory contains the software running inside the Payload.

The Payload carries an experiment designed to measure the acceleration experienced after separation. Its electronics consist of:
- An ESP32-C6 microcontroller
- A microSD card reader
- A BMI088 IMU

The experiment was successful during the C'Space launch. The recorded measurements made it possible to model the Payload's complete dynamics and part of the rocket's dynamics before Payload separation.

### Ground receiver

The `Receiver` directory contains the software for the ground station, which receives flight data in real time.

It is based on an ESP32-C6 and includes:
- An LoRa receiver (RMF95W)
- A microSD card reader
- An OLED display

### Flight sequencer

The `sequencer` directory contains the flight sequencer software. Its purpose is to trigger Payload separation at the rocket's apogee.

The sequencer is based on an ESP32-C6 and includes:
- An MS5611 barometer
- A BMI088 IMU

Although these sensors can be used to determine the rocket's apogee, a timer-based trigger was ultimately selected to keep the sequencer as simple and reliable as possible. This decision was based on the accuracy of the C'Space flight-time predictions.

During the launch, the timer successfully triggered Payload separation at apogee.

## Test programs

The `Test code` directory contains programs used to test individual electronic components before integrating them into the main software.

## Payload orientation simulation

The `rocket_orientation` directory contains a Processing simulation that reconstructs and displays the Payload's orientation using measurements from its IMU.

## Flight outcome

The flight outcome include graphs, simulations, the flight video, and the flight report submitted to C'Space.
